My Projects

VR HERITAGES SITES

Developed an immersive VR experience that allows users to explore historically significant heritage sites in 360°. The project aims to preserve cultural monuments and offer a virtual travel experience for educational and tourism purposes.

CONTACT MANAGER

An web application developed using ReactJS and MySQL to efficiently organize and manage contact information. It features role-based access where the teachers can add, delete, and view student contacts, while students can only view and edit their own profiles. The system supports full CRUD operations and includes advanced search functionality, allowing users to quickly retrieve contacts based on specific criteria such as name, department, and domain.

LIBRARY MANAGEMENT

A web application built with Python and MySQL to streamline book inventory management, user accounts, and transaction tracking. It offers features for borrowing, returning, and searching books, ensuring a user-friendly and responsive experience. The system was developed using Jupyter Notebook for efficient data processing and integration.

AR APPLICATION FOR EDUCATION

Our AR educational application utilizes Unity,Vuforia SDK and Blender to deliver immersive learning experiences of topics like science, space, English, insects, birds, and complex concepts like anatomy, the solar system,cells and chemical reactions engaging and accessible via mobile devices.

FESTIVAL FACE FILTER

A festival-themed face filter application using Unity and ARCore. The app includes interactive features for various festivals, such as Christmas, Diwali, and Halloween, providing users with immersive filters and festive effects.

DRAIN COVER CLEANER

Drain Cover Cleaner is an automated system with IR and water sensors, a vacuum, and heating elements to efficiently remove debris and prevent clogging in drainage systems. It won 2nd place in Ideathon at Kongu Engineering College. 🚀.

BOUNCE BALL

Developed a fast-paced 2D bounce ball arcade game in Unity, focusing on reflex-based gameplay and intuitive mechanics. The game challenges players to control a bouncing ball across dynamic platforms while avoiding obstacles and collecting points.

ABACUS GAME

Designed and developed an interactive Abacus Game to make learning basic arithmetic fun and engaging for children. The game combines traditional abacus concepts with gamification and immersive technology to create a unique educational experience.
